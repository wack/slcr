# slcr

A CLI for SLCR specifications: requirements stored as a graph, serialized as
YAML, JSON, or TOML, and checked by the validators a project declares.

## Install

With [Homebrew](https://brew.sh), on macOS or Linux:

```bash
brew install wack/tap/slcr
```

Or with the shell installer from the
[latest release](https://github.com/wack/slcr/releases/latest).

## Teach your agent SLCR

[`skills/slcr`](skills/slcr) is a Claude skill that teaches coding agents to
use SLCR. See [`skills/README.md`](skills/README.md) to add it to your
repository.
